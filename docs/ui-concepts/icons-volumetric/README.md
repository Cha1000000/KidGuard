# Объёмные иконки: как они сделаны и как править

Набор для экрана «Правила» (родитель) и «Сегодня» (ребёнок). Плоские Material-иконки выглядели
чужеродно рядом с объёмной иконкой приложения и общим стеклянным стилем.

## Что где лежит

| Файл | Что это |
|---|---|
| `icons-mockup.html` | Согласованный макет: экраны «до/после», витрина крупно, проверка мелких размеров |
| `svg/*.svg` | **Исходники иконок.** Правки вносить сюда, а не в VectorDrawable |
| `svg2vd.py` | Конвертер SVG → VectorDrawable |
| `../../app/src/main/res/drawable/ic_*_solid.xml` | Результат, который использует приложение |

## Как править иконку

```bash
# 1. правим svg/ic_clock_solid.svg
# 2. смотрим результат
rsvg-convert -w 128 svg/ic_clock_solid.svg -o /tmp/check.png
# 3. конвертируем
python3 svg2vd.py svg/ic_clock_solid.svg ../../app/src/main/res/drawable/ic_clock_solid.xml
```

Комментарий-шапку в готовом XML после переконвертации нужно вернуть руками — конвертер её не знает.

## Почему свой конвертер

`svg2vectordrawable` (npm) для этого набора не подошёл: молча выбрасывает `<circle>` и `<ellipse>`
(в иконках это почти всё) и неверно пересчитывает координаты градиентов из `objectBoundingBox` —
получались значения вроде `startX="470"` при viewport 96.

`svg2vd.py` поддерживает ровно то, что используется в наборе:

- `circle`/`ellipse`/`rect` разворачиваются в `pathData` дугами;
- градиенты пересчитываются из долей bbox фигуры в абсолютные координаты viewport;
- `transform="rotate(a cx cy)"` превращается в `<group android:rotation/pivotX/pivotY>`;
- `stroke` со всеми атрибутами, в том числе градиентный.

Для `path` bbox не вычисляется по кривым — он задаётся вручную в `MANUAL_BBOX` (сейчас там одна
запись: дужка замка). Если добавится новый `path` с градиентом, конвертер честно упадёт с
подсказкой, а не нарисует мимо.

## Правила набора

1. **Показывать через `Image(painterResource(...))`, а НЕ `Icon`** — `tint` у `Icon` красит
   содержимое одним цветом и убивает градиенты. Это главные грабли.
2. **Цвет заложен в иконку**, параметры `iconTint`/`iconBackground` у карточек убраны: запреты
   красные, остальные бирюзовые. Подложки-квадраты под иконками тоже убраны — они нужны были,
   чтобы оживить плоский значок.
3. **Только крупные размеры.** Ниже 24dp градиенты и блики сливаются в кашу, поэтому док-панель,
   кнопки и служебные значки (крестик, галочка выбора, «три точки») остаются плоскими.
4. **Теней нет:** VectorDrawable не поддерживает `feDropShadow`. Объём держится на градиентах,
   бликах и затемнённых деталях.
5. Гамма фирменная: бирюза `#BFEDE5→#2B7C84`, золото `#FFE7A0→#B87A1C`, красный `#F6B0AB→#8E2F2A`.
