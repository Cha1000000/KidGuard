Объёмные иконки вместо плоских

Слева — как выглядит сейчас, справа — с объёмными иконками. Формы те же, чтобы не пришлось переучиваться: часы, секундомер, календарь, галочка, знак запрета, глобус, замок. Объём собран градиентами и бликами — вектор, вес приложения не растёт.
