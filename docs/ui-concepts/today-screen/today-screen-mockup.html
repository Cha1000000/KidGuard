Экран «Сегодня»: сетка 2×2, стеклянная плашка, error-состояние

Самый частый экран приложения (открывает ребёнок), сильнее всех разошёлся с исходным макетом вехи 6Б. Что меняется:

  • «Мои правила» — сетка 2×2 вместо вертикального списка из 3 строк: «Лимиты», «Запрещено», «Доступно», плюс новая карточка «Статистика» — сколько уже наиграно сегодня (сейчас этой цифры на экране нет вообще, хотя данные для неё уже читаются в TodayViewModel, просто не выводятся в UI).
  • Статус защиты — стеклянная плашка вместо голой строки текста: тот же ic_shield_logo и тот же текст, просто на полупрозрачном фоне с рамкой, как остальные стеклянные поверхности приложения.
  • Error-состояние — сейчас при сбое синхронизации (нет сети, ошибка сервера) экран вечно крутит спиннер и ничего не объясняет. Добавляется понятное сообщение (EmptyState из Фазы 2).

Откуда берётся «Сегодня» в сетке

Значение уже вычисляется в TodayViewModel.computeTime() как usedSeconds / 60 — используется только для расчёта остатка в кольце, наружу не отдаётся. Нужно добавить это же число полем в TodayUiState, второй запрос на sync не потребуется.

Почему карточки компактнее списка

Текущий список показывает превью (до 3 названий приложений) — в сетке 2×2 места меньше, оставляем count + одну короткую подсказку, где есть место (как в «Лимиты» на первом экране). Полный список названий по-прежнему можно посмотреть в других местах приложения родителем — на детском экране это была витрина, а не единственный источник.

Что с error-состоянием дальше

Это минимальное улучшение по формулировке аудита — заменить бесконечный спиннер понятным сообщением. Полноценный retry (кнопка «Повторить», которая передёргивает подписку) — вне рамок этой фазы, экран пересоберётся сам при следующем реактивном обновлении данных (флоу переподпишется, если родитель/сеть восстановятся и придёт новое значение).

Что не меняется

Кольцо остатка времени, карточки «Время вышло»/«Без лимита», приветствие с аватаром — без изменений. Смешение иконок (Icons.Filled.MoreVert/CheckCircle vs кастомные SVG) и подсказка «аватар кликабелен» — отдельные мелкие находки аудита, не входят в эту фазу, чтобы не раздувать её.
