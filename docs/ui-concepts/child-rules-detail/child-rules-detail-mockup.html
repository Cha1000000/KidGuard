Детальные экраны «Мои правила» — по тапу на карточки сетки 2×2

Сейчас 4 карточки сетки на экране «Сегодня» (Лимиты / Запрещено / Доступно / Сегодня) — просто витрина с цифрой, некликабельны. Задача: по тапу открывать детальный список. Экраны read-only — ребёнок смотрит свои правила, изменить лимиты/списки может только родитель через свои PIN-защищённые экраны.

  • «Лимиты» — какие приложения ограничены по времени и сколько именно (потрачено сегодня / дневной лимит).
  • «Запрещено» / «Доступно» — простой список приложений, без цифр.
  • «Сегодня» — тот же блок «Экранное время сегодня» + «По приложениям», что и в родительской «Статистике», но БЕЗ выбора ребёнка и БЕЗ графика за неделю (эти два блока Володя явно исключил на скриншоте) — только сегодняшний день.

4 · «Сегодня» — как родительская «Статистика», но без выбора ребёнка и без графика недели

Откуда данные — везде локально, без сети

Все 4 экрана читают ту же связку, что уже использует TodayViewModel: PolicyRepository (лимиты/чёрный/белый список) + UsageRepository (потрачено сегодня по пакетам) + InstalledAppsSource.launchableApps() (имена и иконки с этого же устройства). Сетевых запросов нет — в отличие от родительской «Статистики», которая тянет историю с сервера.

Почему «Сегодня» без графика и без выбора ребёнка

На детском устройстве всегда один ребёнок — свой; выбирать некого. График «последние 7 дней» — по вашему фидбэку, для детского экрана оставляем только сегодняшний срез, без недельной истории.

Пустые состояния

Если списки пустые (например, лимитов на приложения не задано вообще) — вместо пустого экрана показывается EmptyState (тот же компонент, что уже используется на других экранах): иконка + короткая подпись «Нет приложений с лимитом» и т.п.

Что НЕ входит в эту фичу

Экраны только для просмотра — тапнуть по строке приложения в списке и что-то изменить (снять лимит, разблокировать) нельзя. Управление правилами остаётся только у родителя в PIN-защищённых экранах «Правила».
