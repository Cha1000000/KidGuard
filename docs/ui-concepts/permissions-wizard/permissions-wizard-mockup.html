Мастер разрешений: прогресс, группировка, предупреждение

Экран PermissionsWizardScreen — самый рискованный для отвала родителя на середине настройки (7 разрешений подряд, без единой карточки не понять, сколько ещё осталось). Что меняется:

  • Счётчик + степ-индикатор сверху — «Выдано 3 из 7» и полоска прогресса (переиспользуем LinearStepIndicator, уже сделан в Фазе 2).
  • Группировка «Обязательные» / «Дополнительные» — данные для этого уже есть (обязательные пять — те же, что входят в DeviceHealth: Спец. возможности, Поверх экрана, Администратор устройства, Без оптимизации батареи, VPN; дополнительные — Уведомления и Экстренный звонок). У обязательных, если не выданы — маленький бейдж «ОБЯЗАТЕЛЬНО».
  • Кнопка «Продолжить» не блокируется (родитель может решить донастроить позже), но если не хватает обязательных — по тапу сначала показывается предупреждение (GlassDialog из Фазы 2) с конкретным списком, что не выдано, и явным выбором «Вернуться» / «Всё равно продолжить».
  • Иконки по разрешениям — черновой вариант для структуры, финальный подбор (как с кофе/рюкзаком/луной) сделаем отдельно перед реализацией.

2 · Тап «Продолжить» с недостающими обязательными — GlassDialog с конкретным списком

Почему предупреждение, а не блокировка кнопки

Полная блокировка «Продолжить» до выдачи всех 7 разрешений жёстче, чем сейчас, и рискует просто застопорить часть родителей на VPN-разрешении (отдельный системный флоу, может захотеться сделать позже). Предупреждение с явным выбором — тот же эффект «не дать пройти мимо не глядя», но без жёсткого тупика.

Откуда список «обязательных»

Ровно те 5 разрешений, что входят в DeviceHealth.brokenPermissions() (core/domain/model/DeviceHealth.kt) — то же самое множество, о поломке которого родителю уже сигналит watchdog на карточке ребёнка. Дублировать логику не придётся, критерий «обязательности» уже есть в коде.

Что не меняется

Порядок разрешений внутри своей секции — как в DevicePermission enum (он же порядок шагов). Карточки автозапуска/VPN (InfoActionCard, Фаза 2) остаются после списка, без своей секции — они не входят в счётчик «N из 7», это отдельные рекомендации без проверяемого статуса.

Иконки — черновик

Символы на макете — только чтобы показать расположение (кружок слева от текста). Финальный подбор — как с иконками кофе/рюкзака/луны: соберу 3-4 варианта на каждое разрешение из разных наборов в реальном масштабе карточки, покажу файлом перед тем, как вписывать в код.
